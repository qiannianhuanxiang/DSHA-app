# DSHA 0.2.1-rc.3-bxroot.15-dsh0.2.1-rc.3 / build217

- 화면 조작 일시 중지를 해제할 수 없던 구조적 원인을 수정했습니다. 일시 중지 사유는 11가지인데 대부분 해제 경로가 없었고, 조건이 아직 성립하는지 기록하는 곳도 없었습니다. 이제 각 구성 요소가 조건(패널 펼침, 편집기 표시, 음성 인식 중, 오버레이 연결)을 공개하고, 조건이 실제로 끝났을 때만 해제합니다. 답이 없으면 계속 중지된 것으로 봅니다.
- 음성 입력 수정: 마이크를 누르면 화면 조작이 중지되지만 음성 UI가 끝난 뒤 해제하는 코드가 없어 프로세스를 종료해야 했습니다. 이제 인식이 끝나면 해제합니다.
- 텍스트 입력 수정: 입력창을 열면 중지되고 닫아도 중지가 남아 있었습니다. 이제 편집기를 닫으면 해제합니다.
- 플로팅 어시스턴트 패널 수정: 펼쳤다가 접어도 `ASSISTANT_PANEL_EXPANDED` 중지가 남지 않습니다.
- 사용자 일시 중지, 중지 알림 규칙, 정책 및 상태 실패는 여전히 자동 해제되지 않습니다.
- 나머지는 build214와 같습니다: bxroot 런타임, Termux 경로 호환, 시작 및 압축 해제 가속, 네이티브 호출 명령.
- 이번에는 실기기에서 검증하지 않았습니다. `SCREEN_CONTROL_PAUSED`가 계속 나오면 `adb logcat -s DSHA`에 `checkBegin refused: paused reason=...`가 출력되어 원인을 알 수 있습니다.
