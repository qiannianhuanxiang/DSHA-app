# DSHA 0.2.1-rc.3-bxroot.15-dsh0.2.1-rc.3 / build217

- 修复屏幕操作暂停无法恢复的结构性问题：暂停原因有 11 种，但多数没有对应的清除路径，也没有地方记录「暂停的条件是否还存在」。现在由各组件上报条件状态（面板展开、编辑器可见、语音识别中、悬浮窗挂载），只有条件确实结束才释放暂停；查不到状态一律按仍暂停处理。
- 修复语音输入：点麦克风会暂停屏幕操作，但语音界面退出后没有任何代码清除，只能杀进程恢复。现在语音识别结束即释放。
- 修复文字输入：打开输入框暂停屏幕操作，关闭后暂停一直留着。现在关闭编辑器即释放。
- 修复悬浮助手面板：展开后收起，`ASSISTANT_PANEL_EXPANDED` 暂停不再残留。
- 用户主动暂停、停止通知规则、策略与状态失败仍然永不自动释放。
- 其余与 build214 相同：bxroot 运行时、Termux 路径兼容、启动与解压提速、原生调用命令。
- 本轮未在真机验证。若仍返回 `SCREEN_CONTROL_PAUSED`，`adb logcat -s DSHA` 会打出 `checkBegin refused: paused reason=...`，可直接看出原因。
