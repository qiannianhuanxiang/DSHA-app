# DSHA 0.2.1-rc.3-bxroot.14-dsh0.2.1-rc.3 / build216

- 修復螢幕操作 `begin` 永久失敗：停止通知的比對寫死了通知 id，實際通知 id 不同，因此每次都被判定為「缺少停止通知」並暫停螢幕操作；這個暫停在助手服務結束後沒有任何路徑能清除，重新啟動 App 也只在重新啟動後短暫可用。現在改為依停止動作比對通知，並在需要它的服務已結束時只釋放這一種原因的暫停（使用者主動暫停等其它原因不受影響）。
- 保留 build215 的修正：恢復螢幕操作時先收合助手工作階段，避免展開旗標把剛恢復的操作再次暫停。
- 其餘與 build214 相同：bxroot 執行環境、Termux 路徑相容、啟動與解壓加速、原生呼叫命令。
- 本輪未在實機驗證：安裝後請呼叫 `/app/ui/task-begin`，確認不再回傳 `SCREEN_CONTROL_PAUSED`。
