# DSHA 0.2.1-rc.3-bxroot.13-dsh0.2.1-rc.3 / build215

- 修復螢幕操作「恢復」後仍回傳 `SCREEN_CONTROL_PAUSED`：恢復時未清除助手的展開旗標，助手面板每次版面變化都會重新發佈幾何資訊並再次暫停螢幕操作。現在恢復前會先收合助手工作階段，兩個旗標一起清除；主動展開時的暫停邏輯不變。
- 保留 build214 的 bxroot 執行環境、Termux 路徑相容、啟動與解壓加速、原生呼叫命令，以及 dsh-web-mobile 3.2.2、DSH rc.3、本機與區域網路存取、十種語言。
- 本輪只做這一處修正，未在實機驗證：請在設定 → 裝置能力授權 → 螢幕操作裡點一次「恢復助手螢幕操作」，再呼叫 `/app/ui/task-begin` 確認不再回傳 `SCREEN_CONTROL_PAUSED`。
