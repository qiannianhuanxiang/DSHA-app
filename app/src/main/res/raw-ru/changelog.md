# DSHA 0.2.1-rc.3-bxroot.15-dsh0.2.1-rc.3 / build217

- Исправлена структурная причина, по которой паузы управления экраном не снимались: причин было 11, но у большинства не было пути снятия, и нигде не записывалось, сохраняется ли условие паузы. Теперь компоненты публикуют своё состояние (панель раскрыта, редактор виден, распознавание речи активно, оверлей прикреплён), и пауза снимается только когда условие действительно закончилось; отсутствие ответа считается «всё ещё на паузе».
- Исправлен голосовой ввод: нажатие микрофона ставило управление экраном на паузу, но после выхода из голосового интерфейса её ничто не снимало, помогало только завершение процесса. Теперь снятие происходит по окончании распознавания.
- Исправлен текстовый ввод: открытие поля ввода ставило паузу, а закрытие её не снимало. Теперь закрытие редактора снимает паузу.
- Исправлена плавающая панель ассистента: раскрытие и последующее сворачивание больше не оставляют паузу `ASSISTANT_PANEL_EXPANDED`.
- Паузы пользователя, правила уведомления об остановке, политики и сбои состояния по-прежнему никогда не снимаются автоматически.
- В остальном совпадает с build214: среда bxroot, совместимость путей Termux, ускорение запуска и распаковки, команды нативных вызовов.
- На устройстве в этот раз не проверялось. Если `SCREEN_CONTROL_PAUSED` всё ещё появляется, `adb logcat -s DSHA` печатает `checkBegin refused: paused reason=...` и называет причину.
