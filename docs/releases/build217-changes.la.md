- Emendatus est introitus litterarum: aperire campum imperium sistebat, claudere moram relinquebat. Nunc editor clausus solvit.
- Emendata est tabula adiutoris natans: expandere deinde contrahere moram `ASSISTANT_PANEL_EXPANDED` non iam relinquit.
- Morae a usuario positae, regulae nuntii sistendi, consilia et casus status numquam sponte solvuntur.
