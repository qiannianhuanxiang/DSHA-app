# DSHA 0.2.1-rc.3-bxroot.13-dsh0.2.1-rc.3 / build215

- 画面操作の「再開」後も `SCREEN_CONTROL_PAUSED` が返る問題を修正: 再開時にアシスタントの展開フラグを消しておらず、アシスタントパネルはレイアウト変更のたびにジオメトリを再公開して画面操作を再び一時停止していました。再開前にアシスタントセッションを折りたたみ、両方のフラグを同時に消すようにしました。展開時の意図的な一時停止は変わりません。
- build214 の bxroot ランタイム、Termux パス互換、起動と展開の高速化、ネイティブ呼び出しコマンド、dsh-web-mobile 3.2.2、DSH rc.3、ローカル/LAN アクセス、十言語を維持します。
- 本ビルドはこの修正のみで、実機未検証です。「設定 → デバイス権限 → 画面操作」で「アシスタントの画面操作を再開」を一度押し、`/app/ui/task-begin` を呼んで `SCREEN_CONTROL_PAUSED` が返らないことを確認してください。
