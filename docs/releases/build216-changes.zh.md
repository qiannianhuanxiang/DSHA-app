# DSHA 0.2.1-rc.3-bxroot.14-dsh0.2.1-rc.3 / build216

- 修复屏幕操作 `begin` 永久失败：停止通知的匹配写死了通知 id，实际通知 id 不同，于是每次都被判定为「缺少停止通知」并暂停屏幕操作；这个暂停在助手服务退出后没有任何路径能清除，重启 App 也只在重启后短暂可用。现在按停止动作匹配通知，并且在需要它的服务已退出时只释放这一种原因的暂停（用户主动暂停等其它原因不受影响）。
- 保留 build215 的修复：恢复屏幕操作时先收起助手会话，避免展开标志把刚恢复的操作再次暂停。
- 其余与 build214 相同：bxroot 运行时、Termux 路径兼容、启动与解压提速、原生调用命令。
- 本轮未在真机验证：安装后请调 `/app/ui/task-begin`，确认不再返回 `SCREEN_CONTROL_PAUSED`。
