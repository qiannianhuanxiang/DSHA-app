# DSHA 0.2.1-rc.3-bxroot.14-dsh0.2.1-rc.3 / build216

- 画面操作の `begin` が恒久的に失敗する問題を修正: 停止通知の判定が通知 id を固定値で比較していましたが、実際の通知は別の id で投稿されるため、毎回「停止通知がない」と判定されて画面操作が一時停止していました。アシスタントサービス終了後、この一時停止を解除する経路はなく、アプリの再起動も一時的にしか効きませんでした。現在は停止アクションで照合し、それを必要としたサービスが終了している場合はこの理由の一時停止だけを解除します。ユーザーによる一時停止など他の理由には影響しません。
- build215 の修正を維持: 画面操作を再開する前にアシスタントセッションを折りたたみ、展開フラグが再開直後の操作を再び停止しないようにします。
- それ以外は build214 と同じ: bxroot ランタイム、Termux パス互換、起動と展開の高速化、ネイティブ呼び出しコマンド。
- 今回は実機未検証です。インストール後に `/app/ui/task-begin` を呼び、`SCREEN_CONTROL_PAUSED` が返らないことを確認してください。
