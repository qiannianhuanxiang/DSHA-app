# DSHA 0.2.1-rc.3-bxroot.7-dsh0.2.1-rc.3 / build209

- - Исправлено: на системах вроде HyperOS крошечные (1×1) системные окна-глифы/значки (HyperDuo glyph, значок заметок и т.п.) вызывали TARGET_WINDOW_OCCLUDED и делали координатные нажатия и свайпы полностью неработоспособными. Окна пренебрежимо малой площади больше не участвуют в решении о заслонении (#212).
- - Когда остановка приложения блокируется сообщением «формат списка приложений не подтверждён», ошибка теперь содержит первую неожиданную строку (замаскированную, усечённую) и указывает пользовательский или системный список — это помогает выявить различия вывода pm в конкретных ROM (#210, продолжение).
- - Сохранены dsh-web-mobile 3.2.2, DSH rc.3, локальный доступ и доступ по LAN, а также десять языков. Проверка на телефоне остаётся приостановленной.
