# DSHA 0.2.1-rc.3-bxroot.13-dsh0.2.1-rc.3 / build215

- Исправлено: управление экраном продолжало возвращать `SCREEN_CONTROL_PAUSED` после «Возобновить» — при возобновлении не сбрасывался флаг раскрытия ассистента, а панель ассистента заново публикует геометрию при каждом изменении разметки и снова приостанавливала управление. Теперь перед возобновлением активный сеанс ассистента сворачивается, и оба флага сбрасываются вместе; намеренная пауза при раскрытии не изменилась.
- Сохранены из build214: среда bxroot, совместимость путей Termux, ускорение запуска и распаковки, команды нативных вызовов, dsh-web-mobile 3.2.2, DSH rc.3, локальный и LAN-доступ, десять языков.
- В этой сборке только это исправление, на устройстве не проверено: нажмите «Возобновить управление экраном ассистента» в «Настройки → Разрешения устройства → Управление экраном» и вызовите `/app/ui/task-begin`, чтобы убедиться, что `SCREEN_CONTROL_PAUSED` больше не возвращается.
