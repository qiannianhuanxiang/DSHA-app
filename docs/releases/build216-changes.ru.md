# DSHA 0.2.1-rc.3-bxroot.14-dsh0.2.1-rc.3 / build216

- Исправлено: `begin` для управления экраном постоянно завершался ошибкой — проверка уведомления об остановке сравнивала жёстко заданный id, а уведомление публикуется с другим id, поэтому каждый вызов считался «уведомление об остановке отсутствует» и управление экраном приостанавливалось. После выхода службы ассистента эту паузу ничто не снимало, а перезапуск приложения помогал лишь ненадолго. Теперь проверяется действие остановки, и эта конкретная причина паузы снимается, когда службы, которой она требовалась, уже нет; паузы пользователя и другие причины не затрагиваются.
- Сохранено исправление build215: возобновление управления экраном сначала сворачивает сеанс ассистента, чтобы флаг раскрытия не приостановил только что возобновлённое управление.
- В остальном совпадает с build214: среда bxroot, совместимость путей Termux, ускорение запуска и распаковки, команды нативных вызовов.
- На устройстве в этот раз не проверялось: после установки вызовите `/app/ui/task-begin` и убедитесь, что `SCREEN_CONTROL_PAUSED` больше не возвращается.
