# DSHA 0.2.1-rc.3-bxroot.15-dsh0.2.1-rc.3 / build217

- 修復螢幕操作暫停無法恢復的結構性問題：暫停原因有 11 種，但多數沒有對應的清除路徑，也沒有地方記錄「暫停的條件是否還存在」。現在由各元件回報條件狀態（面板展開、編輯器可見、語音辨識中、懸浮窗掛載），只有條件確實結束才釋放暫停；查不到狀態一律視為仍暫停。
- 修復語音輸入：按下麥克風會暫停螢幕操作，但語音介面結束後沒有任何程式碼清除，只能終止行程恢復。現在語音辨識結束即釋放。
- 修復文字輸入：開啟輸入框暫停螢幕操作，關閉後暫停一直留著。現在關閉編輯器即釋放。
- 修復懸浮助手面板：展開後收合，`ASSISTANT_PANEL_EXPANDED` 暫停不再殘留。
- 使用者主動暫停、停止通知規則、策略與狀態失敗仍然永不自動釋放。
- 其餘與 build214 相同：bxroot 執行環境、Termux 路徑相容、啟動與解壓加速、原生呼叫命令。
- 本輪未在實機驗證。若仍回傳 `SCREEN_CONTROL_PAUSED`，`adb logcat -s DSHA` 會印出 `checkBegin refused: paused reason=...`，可直接看出原因。
