# DSHA 0.2.1-rc.3-bxroot.13-dsh0.2.1-rc.3 / build215

- 修复屏幕操作「恢复」后仍然返回 `SCREEN_CONTROL_PAUSED`：恢复时没有清除助手的展开标志，助手面板每次布局变化都会重新发布几何信息并再次暂停屏幕操作。现在恢复前会先收起助手会话，两个标志一起清除；主动展开时的暂停逻辑不变。
- 保留 build214 的 bxroot 运行时、Termux 路径兼容、启动与解压提速、原生调用命令，以及 dsh-web-mobile 3.2.2、DSH rc.3、本机和局域网访问、十种语言。
- 本轮只做这一处修复，未在真机验证：请在设置 → 设备能力授权 → 屏幕操作里点一次「恢复助手屏幕操作」，再调 `/app/ui/task-begin` 确认不再返回 `SCREEN_CONTROL_PAUSED`。
