# DSHA 0.2.1-rc.3-bxroot.15-dsh0.2.1-rc.3 / build217

- 画面操作の一時停止が解除できない構造的な原因を修正: 一時停止の理由は 11 種類あるのに、ほとんどの解除経路がなく、条件がまだ成立しているかを記録する場所もありませんでした。各コンポーネントが条件（パネル展開、エディタ表示、音声認識中、オーバーレイ接続）を公開し、条件が実際に終わったときだけ解除します。答えが得られない場合は停止中のままとして扱います。
- 音声入力の修正: マイクを押すと画面操作が停止しますが、音声 UI 終了後に解除するコードがなく、プロセスを終了するしかありませんでした。認識終了時に解除します。
- テキスト入力の修正: 入力欄を開くと停止し、閉じても停止が残っていました。エディタを閉じると解除します。
- フローティングアシスタントパネルの修正: 展開してから折りたたんでも `ASSISTANT_PANEL_EXPANDED` の停止が残らなくなりました。
- ユーザーによる停止、停止通知の規則、ポリシーや状態取得の失敗は従来どおり自動解除しません。
- それ以外は build214 と同じ: bxroot ランタイム、Termux パス互換、起動と展開の高速化、ネイティブ呼び出しコマンド。
- 今回は実機未検証です。`SCREEN_CONTROL_PAUSED` がまだ出る場合、`adb logcat -s DSHA` に `checkBegin refused: paused reason=...` が出て原因が分かります。
