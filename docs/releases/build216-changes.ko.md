# DSHA 0.2.1-rc.3-bxroot.14-dsh0.2.1-rc.3 / build216

- 화면 조작 `begin`이 영구적으로 실패하던 문제를 수정했습니다. 중지 알림 검사에서 알림 id를 고정값으로 비교했지만 실제 알림은 다른 id로 게시되어 매번 '중지 알림 없음'으로 판정되고 화면 조작이 일시 중지되었습니다. 어시스턴트 서비스가 종료된 뒤에는 이 일시 중지를 해제할 경로가 없었고 앱을 다시 시작해도 잠시만 효과가 있었습니다. 이제 중지 액션으로 대조하고, 그것을 필요로 하던 서비스가 없을 때 이 사유의 일시 중지만 해제합니다. 사용자가 직접 건 일시 중지 등 다른 사유는 그대로입니다.
- build215 수정을 유지합니다. 화면 조작을 재개할 때 어시스턴트 세션을 먼저 접어, 펼침 플래그가 방금 재개한 조작을 다시 중지하지 않게 합니다.
- 나머지는 build214와 같습니다: bxroot 런타임, Termux 경로 호환, 시작 및 압축 해제 가속, 네이티브 호출 명령.
- 이번에는 실기기에서 검증하지 않았습니다. 설치 후 `/app/ui/task-begin`을 호출해 `SCREEN_CONTROL_PAUSED`가 더 이상 나오지 않는지 확인하세요.
